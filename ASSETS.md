# Assets

Every file under `public/` ships with the game: `npm run build` copies it into `dist/`, and the Electron build will bundle it. Each one is listed below with its source, author, licence and use.

`tests/assets.test.ts` fails if a file under `public/` has no row here, if a row names a file that does not exist, or if a row's licence is not `CC0-1.0`, `OFL-1.1` or `Own work`. Add the row in the same change as the file.

## Not shipped

- `assets/source/grafxkid-td-racing-assets.png`: the original sheet (CC0, GrafxKid), committed so the slicer runs offline. `scripts/fetch-assets.mjs` downloads it again and checks its pinned SHA-256. It is input to the slicer only.
- Parts of the sheet left out of the atlas: the sheet labels, the two example track layouts, the HUD mock-up (only its fuel gauge is cut out), the player avatars, a few sprites that could not be identified, and pixel-identical duplicates. `python3 scripts/slice-sheet.py` lists each one with its position and the reason.

## Rebuilding

```bash
node scripts/fetch-assets.mjs     # download the sheet into assets/source/ and check its SHA-256
python3 scripts/slice-sheet.py    # needs Pillow; writes public/assets/sprites.png and sprites.json
cp node_modules/@fontsource/press-start-2p/files/press-start-2p-latin-400-normal.woff2 public/assets/font/
cp node_modules/@fontsource/press-start-2p/LICENSE public/assets/font/OFL.txt
```

Behind an HTTPS proxy, run the fetch with `NODE_USE_ENV_PROXY=1` (Node 22.21 or later).

## Art drawn in code

The sheet has no truck. Any sprite it does not provide is drawn in code as a pixel grid in the project's own palette (`docs/ART_PLAN.md` §2). That art is the project's own work. If it is ever exported as a file under `public/`, add a row above with the licence `Own work`.

What is drawn in code, and why (colours are picked from the sheet so it matches):

| Art | Where | Why |
|---|---|---|
| Truck: green cab, white container, 10×20 plus a 1 px shadow, drawn at 3× (the 30×60 hitbox) | `TRUCK` in `src/render/pixelArt.ts` | The sheet has no truck |
| Oil puddle: 10×6, drawn at 4× (the 40×24 hitbox) | `OIL_PUDDLE` in `src/render/pixelArt.ts` | The sheet's `oil_spill` is 6×6, too small and the wrong shape for the hitbox |
| Lane dashes between the three lanes | `drawBackdrop` in `src/render/draw.ts` | The sheet only has a two-lane centre line |
| Goal and fuel gauges, panels and the START button | `src/render/draw.ts`, `src/scenes/` | The sheet's `hud_fuel_gauge` has its fill baked in |

The rainbow fuel car is the sheet's `car_police`, tinted with a hue cycle. That is a tint, not new art.
